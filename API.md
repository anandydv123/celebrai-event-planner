# API Specification — CelebrAI

## 1. Overview
All client-server interactions are routed through Next.js App Router API endpoints (`/app/api/*`). The application strictly avoids client-side `@google/genai` calls, ensuring the `GEMINI_API_KEY` remains securely guarded on the server.

---

## 2. Endpoints

### `POST /api/gemini/plan`
Generates creative, personalized celebration themes, curated food menu recommendations, custom invitations, day-of schedules, and cost-saving tips grounded in the user's specific event inputs.

#### Request Body (`application/json`)
```typescript
interface PlanRequest {
  eventName: string;
  eventType: string;
  totalGuests: number;
  budget: number;
  isStrictBudget: boolean;
  location: string;
  venueType: 'indoor' | 'outdoor' | 'hybrid';
  foodPreference: 'vegetarian' | 'non-vegetarian' | 'mixed';
  theme?: string;
  cakePreference?: {
    flavor: string;
    tiers: number;
    message?: string;
  };
  additionalNotes?: string;
}
```

#### Response (`200 OK`)
```typescript
interface PlanResponse {
  source: 'gemini' | 'deterministic-fallback';
  model?: string;
  themes: Array<{
    title: string;
    description: string;
    colorPalette: string[];
    decorIdeas: string[];
  }>;
  menuSuggestions: Array<{
    course: 'starter' | 'main' | 'bread' | 'rice' | 'dessert' | 'beverage';
    name: string;
    dietary: string;
    suggestedPortionPerPerson: string;
    notes: string;
  }>;
  cakeRecommendation: {
    recommendedWeightKg: number;
    flavors: string[];
    designNotes: string;
  };
  invitationDrafts: Array<{
    tone: 'Warm & Festive' | 'Formal' | 'Playful & Casual';
    text: string;
  }>;
  scheduleOutline: Array<{
    timeSlot: string;
    activity: string;
    notes: string;
  }>;
  costSavingTips: string[];
}
```

#### Error Handling & Graceful Degradation
If `GEMINI_API_KEY` is undefined, or if the model call encounters rate limits, network timeouts, or invalid schema outputs:
- The endpoint catches the error without exposing secrets.
- It returns a high-fidelity plan generated by the deterministic fallback engine (`source: 'deterministic-fallback'`).
- The user is notified transparently in the UI that offline rule-based recommendations are active.
